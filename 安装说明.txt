试卷解析镜（Exam lens）v1.2.0 —— 安装说明
==========================================

把 PDF 试卷拖进面板，框选任意一道题，右侧立刻给出：
  答案 → 知识点 → 可迁移/易混知识点 → 分步解析 → 3 道相似题（含完整选项与答案）


一、先决条件
------------
1. 已安装 DeepSeek Harness（DSH）桌面版，且版本 ≥ 1.2；
2. 当前会话使用的模型支持图片输入（如 deepseek-flash）；
3. 不需要联网安装任何依赖：pdf.js 已经内置在包里。


二、安装（推荐用 tgz）
----------------------
1. 把 exam-analyzer-1.2.0.tgz 复制到本机任意目录，例如 D:\plugins\ ；
2. 在 DSH 里新建一个会话，对 Agent 说：

      用 plugin_manager 安装这个插件：D:\plugins\exam-analyzer-1.2.0.tgz

   （对应调用：plugin_manager  action=install_bundle  target=D:\plugins\exam-analyzer-1.2.0.tgz）

3. 装完刷新页面（Ctrl+R）。页面右下角会出现「📄 试卷解析」按钮。


三、安装（用 zip，适合不能装 tgz 的场景）
-----------------------------------------
1. 解压 exam-analyzer-1.2.0.zip，得到一个 exam-analyzer 目录；
2. 对 Agent 说：
       用 plugin_manager 安装这个插件：<解压出来的 exam-analyzer 目录的绝对路径>
3. 刷新页面。


四、怎么用
----------
1. 点右下角「📄 试卷解析」，选择或拖入一份 PDF 试卷；
2. 左侧显示试卷原图，翻到要做的题；
3. 在题目上按住鼠标拖一个框（把题干和选项一起框进去最准）；
4. 右侧依次出现：原题截图（点击放大）、识别到的题目、答案、知识点、解析、相似题；
5. 想分类整理：在「识别到的题目」下方选学科 → 点「存入题库」，
   之后点顶部「题库 N」查看，支持按学科筛选、关键词搜索、缩略图放大。


五、题库放在哪
--------------
    ~/.dsh/exam-analyzer/question-bank.json     题库（纯 JSON，可备份/迁移/直接编辑）
    ~/.dsh/exam-analyzer/images/*.png           题目里的图形（由模型定位后裁剪）

删除题库条目时，对应图片会一并删除；同一道题重复存入会自动去重。


六、已知限制
------------
- 标签页最小化时 PDF 渲染会暂停，切回前台继续；
- 单份 PDF 最多渲染 40 页，首屏约 1 秒/页；
- 题库里的图形是按“上/下/左/右/整图”的方位裁出来的，复杂版面可能带上一点邻近文字；
- 相似题里的示意图是模型按题意画的 SVG，仅供参考，精确图形以原题为准。


七、卸载
--------
对 Agent 说：用 plugin_manager 卸载 exam-analyzer
（或在「设置 → 插件」里关掉它）。题库文件不会被删除，需要的话手动删 ~/.dsh/exam-analyzer 即可。
